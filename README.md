# Kaboom!-lite

## Номер варіанту 4

---

## Як керувати грою
* **Рух платформи вліво / вправо:** клавіші `A` / `D`.
* **Перезапуск гри:** натиснути кнопку **Restart** на екрані.

---

## Що реалізовано
* **Керування гравцем:** біла платформа рухається горизонталлю та ловить предмети.
* **3 типи предметів, що падають:**
    * Звичайне коло (+10 очок);
    * Цінне коло (+50 очок);
    * Червоний трикутник (небезпечний об'єкт).
* **Спавнер:** генерує об'єкти згори випадковим чином.
* **Складність:** час між появою предметів поступово скорочується.
* **UI (інтерфейс):** показує поточний рахунок (Score), час гри (Timer) та кнопку перезапуску (Restart).
* **Перезапуск:** через кнопку Restart сцена перезавантажується заново.

---

## Що не встигли реалізувати
* Чомусь не спрацьовує колізія червоного трикутника з платформою, досі не можу знайти причину (втрата життів / Game Over при контакті).
* Не виведено окремий лічильник життів (HP) на екран.
* Немає окремого фінального вікна закінчення гри (Game Over / Win screen).

---
